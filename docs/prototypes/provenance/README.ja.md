# 試作 (e): 来歴を目録（ISAD(G)）の形で

ブランチ `proto/provenance`。一言でいうと、各データセットに 2 つ目のページ `/asset/<did>/finding-aid` を設ける試作です。
その記録を ISAD(G) のエリア（3.1〜3.7）に並べ、すべての値に「チェーンに記録」「登録者の申告」「記録なし」のどれかの印を付けます。

- 入口: すべてのデータセットのページで、メタデータの履歴の下に「目録（ISAD(G)）として見る」のリンクがあります。
- 来歴（3.2.3）はチェーンの出来事から組み立てます（登録簿への記載の作成、保管の移転、記述の変更、状態の変更）。どれもブロックエクスプローラの該当トランザクションにリンクします。認められた利用の申し込みは、利用の記録として並べます。
- 登録者が申告した「最終更新日」が、チェーン上の最後の変更より 1 時間以上古いときは、その旨を知らせます。見本のデータセット（InterPARES Indexed Archival Dataset）がこれに当たります。申告は 2025-10-17、チェーンでは 2025-10-20（4 回の編集）です。ここが Vicki さんに見ていただきたい点です。記録の信頼性と、記録が証明できることの違いです。
- 先頭の集計（「22 項目: チェーン 8、登録者 10、記録なし 4」）と「記録なし」の行で、Ocean のスキーマと ISAD(G) の間の隙間が見えるようにしています（言語、数量、関連する単位が無い）。
- 日付はすべて UTC の絶対表記です（「11 か月前」のような書き方はしません）。印刷ボタンがあり、印刷ではサイトのヘッダーとフッターを隠します。
- 文章: `content/findingAid.json` / `.ja.json`。データの値（題名、作成者、ライセンス、タグ、説明）は訳さず、そのまま表示します。コード: `src/components/FindingAid/`、`src/pages/asset/[did]/finding-aid.tsx`。

分かっている限界: ISAD(G) の要素の日本語名は Claude が訳したものです。公刊されている日本語訳と照らし合わせる必要があります。
数量（3.1.5）は埋められません。ファイルの一覧が暗号化されているためです。
サイトの「外部コンテンツは許可されていません」の注意書きが印刷にも出ます。
利用の記録は subgraph から取っています（見本のデータセットでは 2 件）。インデックスサーバ自身の件数（4 件）とは違います。各行がトランザクションにリンクできるので、subgraph の件数だけを出しています。

確認したもの: 日英のデスクトップ、日本語のスマートフォン（390 px）、印刷、ほかの 3 件の記録（アルゴリズム 1 件、有料ダウンロードのデータセット 1 件、作成者の無いデータセット 1 件）。
サイトにダークテーマはありません。
