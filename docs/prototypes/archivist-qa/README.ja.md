# 試作 (g): アーキビストの質問箱

ブランチ `proto/archivist-qa`。一言でいうと、アーキビストが自分の言葉（日英）で Clio-X について尋ねると、用意した答えを出典つきで返す試作です。
文章を生成しないので、作り話の答えは出ません。

- `/archivist-qa`、`/ja/archivist-qa`。ウォレット、サーバ、LLM（大規模言語モデル）は使いません。まだメニューからはつないでいません（URL でのみ開けます）。
- 用意した質問は 20 で、IT への不安に向けたものです（「何か壊してしまいませんか」「お金はかかりますか」「記録が館の外に出ますか」「登録したものを消せますか」「私が何を見たか、他の人に分かりますか」）。言い回しと事実は試作 (a) の用語集に合わせています。
- 照合: ブラウザの中で BM25（検索語の一致度を点数にする方式）を使い、用意した質問と、「資料」のページに既に同梱している InterPARES Trust AI の用語集（588 語）を探します。日本語は辞書を使わず、2 文字ずつ区切って照合します。一致が弱いときは「いちばん近い用意した質問」と注記します。一致しないときは、そう伝え、推測せずに 3 つの質問を示します。
- InterPARES の定義は英語の原文で引用し、サイトの用語集と interparestrustai.org にリンクします。InterPARES に独自の定義が無い語（ウォレット、トランザクション、スマートコントラクトなど）は、そう書いたうえで、InterPARES が引いている外部の定義を引用します。
- どの答えにも出典の印を付けます: 「Clio-X アーキビスト向けの手引き（下書き・未確認）」と「InterPARES Trust AI Terminology」の一方か両方です。
- 既存の RAG チャットボット（資料を検索してから答えを生成する方式）との接続: 同じ文章を、`@utils/chatbot` が送り込む形式（`toKnowledgeChunks`）の知識の断片として書き出せます。チャットボットのサーバ（`CHATBOT_API_URL`、Ollama）がいまは使えないので、実際にはつないで試していません。
- 文章は `content/archivistQa/{qa,ui}(.ja).json`、処理は `src/@utils/archivistQa/` にあります（テスト: 見本の質問 30 件を含む 35 件）。
