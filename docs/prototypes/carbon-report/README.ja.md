# 試作 (f): 書き出せる炭素量と費用の報告書

ブランチ `proto/carbon-report`。一言でいうと、分析を動かす前に、1 か所または複数の場所でのエネルギー、CO2、費用を見積もり、その見積もりを報告書として残す試作です。
報告書は印刷・PDF、CSV、JSON で書き出せます。SHA-256 を付けるので、残したファイルが後で変わっていないか確かめられます。

- `/carbon-report`、`/ja/carbon-report`。ウォレット、ジョブ、支払いは不要です。
- 例: 同じ OCR の作業（40 ジョブ × 30 分）を、ストックホルム、東京、カルガリー、柏（mdx）で比べます。ストックホルム 14.0 gCO2e に対してカルガリー 2.84 kgCO2e（約 203 倍）です。mdx は「求められません」（電力を測っていない）と表示し、順位には入れません。
- 「代わりの場所」（既定）では最小と最大を比べます。これを切ると、各行を足し合わせます。見積もれない行は合計から外します。0 として数えることはしません。
- どの値にも区分（実測 / 事業者の公表値 / ポータルの推計 / 求められない）と出典を付けたままにします。前提と限界も印刷されます。
- 既存の `computeFootprint` の登録簿（コミット fe33bc82）を使っています。英語の報告書に日本語の注記が混ざらないよう、出典の注記に英語版を足しました。
- 文章は `content/carbonReport(.ja).json`、計算と書き出しは `src/@utils/carbonReport.ts` にあります（テスト: `carbonReport.test.ts`）。

ファイル: `report-en-compare.png`、`report-en-combined.png`、`print-ja-page1.png`、`page-en-full.png`、`sample-report-en.pdf`、`sample-ja.csv`。

未決の点: どの機械でも実行時間が同じと仮定しています（実際には GPU が違います）。OCR の処理速度そのものは測っていません。登録簿の値は 2026 年 8 月時点のものです。
