# はじめて見る方へ（動画）

音声の無い 98 秒の動画です。Clio-X の資料のページを 1 つ、英語の字幕で説明します。
誰が資料を保管しているか、永続的な識別子、変更の記録、「計算のみ」、計算の部屋、ネットワークの手数料、ウォレットが要るのは分析を動かすときだけであること。
