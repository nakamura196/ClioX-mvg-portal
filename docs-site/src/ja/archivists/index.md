# はじめに

このページは、Clio-X をはじめて知るアーキビスト・記録管理の方に向けたものです。
情報技術の知識は要りません。

## Clio-X とは

Clio-X は、アーカイブズが資料を記述し、自分たちの条件で共有するための場所です。
資料ごとに、誰でも読める公開の記述が作られます。目録カードのようなものです。
記述には、誰が資料を保管しているか、どんな条件で使えるかが書かれます。
資料によっては、*機関の外に出さずに分析する*ことができます。研究者が分析の手順を送ると、資料のある場所で動き、結果だけが戻ります。
登録・変更・利用の許可は、すべて共有の台帳に書き込まれます。誰も黙って書き換えられません。

## 見るだけなら、何も壊れません

目録を見る、検索する、資料のページを開く。どれも何も変えません。
アカウントもウォレットも要りません。
台帳に書き込む操作（登録・編集・利用の申請）はごく一部で、どれも実行の前に確認の画面が出ます。
