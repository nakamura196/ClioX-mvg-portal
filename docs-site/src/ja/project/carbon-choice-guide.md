# 初めての方へ: 環境への配慮の試作は、何をしているのか

このページは、前提知識のない方に向けた説明です。
「ブロックチェーン」「ウォレット」といった言葉を知らなくても読めるように書いています。

## ひとことで言うと

**デジタルの分析を、どこで動かすかを選ぶとき、排出の少ない場所を選ぶと得をする仕組みを試作しています。**

背景は、2026 年 9 月 30 日の打ち合わせです。
Vicki 先生が、利用者の選択の幅を広げたい、環境への配慮を選びやすくしたい、とおっしゃいました。
それを受けて、2 つの試作を作りました。

- 試作 1: 選んだ場所を、あとから確かめられる形で記録する。
- 試作 2: 排出の少ない場所の利用料を、安くする。

どちらも、試験用のネットワーク（Sepolia）と、架空のお金（PLAY）で動きます。**本物のお金は、いっさい動きません。**

## 先に、言葉を 5 つ

| 言葉                   | ここでの意味                                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| ウォレット（MetaMask） | ブラウザに入れる「財布と印鑑」の道具です。お金を預けるのではなく、「これを承認します」と署名するために使います               |
| Sepolia                | ブロックチェーンの試験用の場所です。練習用で、お金としての価値はありません                                                   |
| PLAY                   | この試作のための架空のお金です。画面のボタンで、いくらでも（1,000 まで）受け取れます                                         |
| 台帳                   | 「いつ、誰が、いくら払ったか」の記録です。書き込まれると、あとから消せず、誰でも見られます                                   |
| 指紋（SHA-256）        | ファイルの中身から作る、短い文字列です。1 文字でも変わると、別の文字列になります。ファイルが変わっていないかの確認に使います |

## 画面に出る数字と言葉

### gCO2e（グラム・シーオーツー・イー）

二酸化炭素に換算した、温室効果ガスの重さ（グラム）です。e は equivalent（換算）の頭文字です。
メタンなど CO2 以外のガスも、温暖化への効き目で CO2 に直して足しています。
この画面では、「その場所で計算機を 1 時間動かしたとき、電気を作るときに出る量」の見積もりです。
14.0 gCO2e は 14 グラム、2.84 kgCO2e は 2.84 キログラムです。

### 「少ない」「中くらい」「多い」

場所ごとの排出（g/時）を、3 つに分けた印です。
既定では、5 以下が「少ない」、20 以上が「多い」、その間が「中くらい」です。
境目は、枠 3 で変えられます。測った値ではなく、ポータルの見積もりで決めています。

### 定価・上乗せ・値引き・補助・負担

| 言葉   | 意味                                                         | 誰のお金か                                              |
| ------ | ------------------------------------------------------------ | ------------------------------------------------------- |
| 定価   | 場所の提供者が決めた料金。提供者は、いつもこれを受け取ります | —                                                       |
| 上乗せ | 排出が「多い」場所で、定価に足される分                       | 利用者が払い、「原資」にたまります                      |
| 値引き | 排出が「少ない」場所で、定価から引かれる分                   | 「原資」から出ます（型 3）                              |
| 補助   | 同じく「少ない」場所で、さらに引かれる分                     | 助成機関が預けたお金から出ます（型 4）                  |
| 負担   | 利用者が実際に払う額                                         | 定価 − 値引き − 補助（「多い」場所では、定価 + 上乗せ） |

例: AWS ストックホルムは、定価 11.16 − 値引き 2.23 − 補助 4.46 = 負担 4.46 PLAY です。

### 原資（げんし）と預け入れ残高

どちらも、値引きや補助の元手になる、ためたお金です。

- **原資（型 3）:** 排出が「多い」場所で集めた上乗せ分をためたものです。外からお金は入りません。空のときは、値引きもありません。
- **預け入れ残高（型 4）:** 助成機関などが預けたお金の、残りです。補助が払われるたびに減ります。

画面では、枠 3 の「型 3 の原資」「型 4 の預け入れ残高」に、今の額が出ます。
払ったとき、この額がどう減るかを見ると、お金の流れが分かります。

## 画面の順に説明します

https://cliox.ldas.jp/ja/carbon-choice を開くと、上から順に 5 つの枠があります。

### 枠 1「仕事の内容」

**何のための分析か、どれだけの量か**を入れます。
例: 「デジタル化した約 12,000 コマの文字認識（OCR）」、ジョブ数 40、1 件あたり 30 分。

これは、排出の見積もりの**計算の元**になる数字です。
実際の機械の速さは違うので、「どこでも同じ時間で終わる」という仮定で計算しています。

### 枠 2「どこで動かすか」

分析を動かせる場所が、横並びで出ます。
場所ごとに、1 時間あたりの CO2 の見積もり、費用、棒グラフが出ます。

- 例: AWS ストックホルム（排出が少ない）、AWS 東京（多い）。
- 消費電力を測っていない場所は「比べられない場所」として別に出ます。順位には入れず、0 とも数えません。
- 数字の信頼の度合いも出ます（実測・事業者の公表値・ポータルの推計）。

**ここで選んだ場所が、次の枠の料金や、記録の中身になります。**

注意: これは「2 つの見積もりの差」です。「本来出たはずの量」と比べた削減量ではありません。

### 枠 3「利用料の決め方（試作）」← 試作 2

選んだ場所の**利用料が、場所の排出によってどう変わるか**を試す場所です。
ここが、今回の中心です。

- **仕組みの選択**: 料金の決まりのセットを選びます。#1 は Clio-X の見本、自分で作ることもできます。
- **型 3「上乗せと値引き」**: 排出の多い場所は、料金に上乗せします。その分をためて「原資」にします。排出の少ない場所は、原資から値引きします。外からお金は入りません。
- **型 4「補助の預け入れ」**: 研究助成の機関などが、お金を預けます。排出の少ない場所を選ぶと、利用料の一部を、そこから払います。
- **「架空のお金を受け取る」**: PLAY をもらうボタンです。
- **「〜で払う」**: 払うと、金額と内訳が台帳に残ります。
- **「預ける」**: 型 4 の預け入れを、実際に行うボタンです。
- **台帳**: 払われるたびに、1 行増えます。上乗せ、値引き、補助が、いくらだったかが見えます。

**場所を提供する側は、いつも定価を受け取ります。** 変わるのは、利用者が払う分だけです。

### 枠 4「記録を残す」← 試作 1

枠 2 で選んだ結果を、**あとから確かめられる形で残す**場所です。

1. 「記録を書き出す」で、選んだ内容のファイル（JSON）を保存します。
2. その指紋を、Sepolia に書き込みます（「この選択を記録する」）。ファイルそのものは、あなたの手元に残ります。
3. 書き込んだものは、他人に譲れない形のトークン（札）になります。

あとからファイルが変えられていないか、指紋で確かめられます。

![実際の画面: 枠 3 の下半分（払うボタンと台帳）と、枠 4。台帳の最後の行（#5）は、東京で払った 28.01 PLAY です](/carbon-choice-guide/box3-4.png)

_実際の画面: 枠 3 の下半分（払うボタンと台帳）と、枠 4。台帳の最後の行（#5）は、東京で払った 28.01 PLAY です_

あなたのウォレットが持つ、記録（トークン）の一覧です。
「記録のファイルを確かめる」で、手元のファイルを選ぶと、指紋が一致するかが分かります。

## 試作 1 と試作 2 の関係

|                         | 何をする                         | 得をするのは誰か               |
| ----------------------- | -------------------------------- | ------------------------------ |
| 試作 1（枠 1・2・4・5） | 選んだ場所を記録する             | 誰も得をしない。記録が残るだけ |
| 試作 2（枠 3）          | 排出の少ない場所の利用料を下げる | 排出の少ない場所を選んだ利用者 |

Vicki 先生の狙いは、「得をする」ことでした。
試作 1 は、記録だけで、得がありません。そこで試作 2 を足しました。
払うと、記録の指紋も一緒に台帳に残ります。2 つは、つながっています。

## この試作が、していないこと

- **排出を減らしたことの証明ではありません。** 排出は、ポータルの見積もりです。測った値ではありません。
- **売れるクレジットではありません。** 排出削減を数にして売ると、測定の信頼や認証の扱いで行き詰まります（2023 年の Toucan / Verra の例）。そのため、「価格の差」で報いる形にしました。
- **実際のジョブとのつながりは、記録だけです。** 計算の画面で、ジョブの詳細に「このジョブの環境配慮料を払う」というリンクがあります。払うと、ジョブ ID の指紋が台帳に残り、「ジョブ」の列で、どの支払いがどのジョブのものか分かります。ただし、払っても分析は始まらず、変わりもしません。選んだ場所は見積もりで、本物のジョブは Clio-X の 1 台のノードで動きます。

## まだ決まっていないこと

**誰がお金を出すか。** 次の 4 通りがあります。

1. 場所の事業者が、価格を下げる。
2. ポータルが、手数料を下げる。
3. 型 3: 上乗せと値引きの収支をゼロにする。
4. 型 4: 助成機関などが預ける。

詳しくは、[環境にやさしい選択に、利益を戻す](./green-choice) をご覧ください。
