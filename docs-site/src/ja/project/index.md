# Clio-X プロジェクトの方へ

Vicki Lemieux 先生のグループと Clio-X チームに向けたページです。
2026 年 9 月に作ったもの・分かったことを報告し、一緒に決めたいことを挙げます。

## この作業のねらい

Clio-X は、情報系の背景を持たないアーキビストが、データや計算が自分の仕事にどう関わるかを知る入口になりえます。
ただ、情報技術に不安を持つ方は少なくありません。
そこで下の試作は、まず不安を下げることを狙いました。アーカイブズの言葉で説明する、危険なく見て回れる、触る前に見られる。

もう 1 つは実務的なねらいです。**Pontus-X に加盟していなくても** Clio-X を試せるようにすること。
そのために、試験用ネットワーク Sepolia に、自前の Ocean Node と subgraph で試用環境を作りました。

## 要点

- 試用環境は [cliox.ldas.jp](https://cliox.ldas.jp/ja) で動いていて、2026 年 9 月 26 日から公開しています。試験用の通貨しか使いません。
- 資料と分析を登録し、ノードの上で分析を動かし、結果だけを受け取る。この一巡が通りました。
- いちばん大事な発見は技術の話ではありません。**資料は、登録に使ったサービスに結び付いたままになります。**
  そのサービスが無くなると、何も消していないのに、資料はどの目録からも見えなくなります。
  保管と永続性に関わるので、アーキビスト向けに書きました:
