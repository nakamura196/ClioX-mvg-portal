# 相談したいこと

Clio-X チームと一緒に決めたいことです。

## 方向

1. **どの試作を続けるか。** [試作の一覧](./prototypes) を参照。どれも小さく、別のブランチにあります。
2. **Pontus-X の外での試用を歓迎していただけるか。** Sepolia の試用環境では、加盟しなくても Clio-X を試せます。2026 年 9 月 26 日から公開していて、試験用の通貨しか使いません。本番のネットワークは Pontus-X のままです。Clio-X チームの意向によっては、閉じるか、利用者を絞ります。
3. **アーキビスト向けの文章を誰に確かめていただくか。** 用語の手引き（13 語）、20 の答え、動画の字幕は下書きです。できれば英語と日本語の両方で、アーキビストの確認が必要です。

## 保管と永続性

[登録に使ったサービスが無くなったとき](/ja/archivists/when-a-node-closes) から:

4. 加盟する機関に、自分で管理する名前で登録し、ノードの鍵を保管するよう求めるべきか。
5. ノードの間で資料を移す手段を、Clio-X が用意すべきか。
6. Clio-X 上の資料の*保管者*を、たまたま使ったノードではなく、機関そのものにできないか。
7. 目録がノードの閉鎖を越えて残るよう、記述を封印せずに登録すべきか。

## 利用の許可

8. **分析を動かせる人をどう決めるか。** Ocean Node には公式の方法が 3 つあります。アドレスの一覧（いまの試用環境）、複数のノードで共有できる台帳上のアクセスリスト、資格情報を確かめるポリシーサーバ（Pontus-X の方式）。参加機関向けに台帳上のリストを 1 つ持つのが合いそうです。

## 用語

10. 目録（ISAD(G)）の試作で使った項目の日本語名は、こちらで訳したものです。公刊の日本語訳との照合が必要です。
