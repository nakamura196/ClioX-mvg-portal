# 試験用のお金

**Sepolia の試用で支払いに使うのは、すべて試験用のトークンです。価値は無く、本物のお金に替えることもできません。**
Sepolia は、イーサリアムの公開の試験用ネットワークです。そのコインは「フォーセット」（ウォレットに少しずつ無料で送ってくれるウェブページ）で配られています。

有料の資料を試すには、ウォレットに次の 2 つが要ります。

1. **Sepolia の ETH**: 取引ごとのネットワークの手数料（「ガス代」）に使います。無料の資料を取り出すときにも要ります
2. **その資料の値付けに使われているトークン**: JPYC・USDC・WETH のどれか（[価格の通貨の決まり方](/ja/developers/price-tokens) を参照）

## それぞれの手に入れ方

| 何を        | どこで                                                                                                    | 補足                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Sepolia ETH | [Google Cloud の Sepolia フォーセット](https://cloud.google.com/application/web3/faucet/ethereum/sepolia) | Google へのログインが要ります                                                         |
| JPYC        | [JPYC のフォーセット](https://faucet.jpyc.co.jp/)                                                         | JPYC 社が運営しています。1 JPYC は 1 円に当たる設計ですが、Sepolia のものは試験用です |
| USDC        | [Circle のフォーセット](https://faucet.circle.com/)                                                       | Ethereum Sepolia を選びます。1 回 20 USDC、2 時間に 1 回まで（2026-11-24 時点の記録） |
| WETH        | 手元の Sepolia ETH を包む                                                                                 | WETH のコントラクトの `deposit()` に ETH を送ると、同じ量の WETH が返ってきます       |

トークンのアドレス（ウォレットに登録すると残高が見えます）:

| トークン | アドレス                                     | 小数の桁 |
| -------- | -------------------------------------------- | -------- |
| JPYC     | `0xE7C3D8C9a439feDe00D2600032D5dB0Be71C3c29` | 18       |
| USDC     | `0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238` | 6        |
| WETH     | `0xfFf9976782d46CC05630D1f6eBAb18b2324d6B14` | 18       |

トークンを登録する前に、アドレスを確かめてください。同じ名前の別の試験用コントラクトが、フォーセットやウォレットに出てくることがあります。

## スクリプトから使うとき

- **WETH:** `deploy/trial/paid.mjs buy <did>` は、買う前に自分で ETH を WETH に包みます（鍵は `paid.zsh` が 1Password から読みます）
- **JPYC:** JPYC のフォーセットのページは、JPYC のフォーセットのコントラクトの `sendToken(to, amount)` を呼んでいます。LDAS Pay は同じ関数をスクリプトから呼び、自分のウォレットに補充しています（`ldas-pay/scripts/setup/claim-jpyc-sepolia.zsh <量>`）

## OCEAN を使わない理由

Sepolia の Ocean のトークン（`0x1B083D8584dd3e6Ff37d04a6e7e82b5F622f3985`）は持ち主しか発行できず、フォーセットもありません。
試用のウォレットから試しに発行しようとすると、_Ownable: caller is not the owner_（持ち主ではない）で失敗しました。
そのため試用では、だれでも手に入るトークンで値付けしています（[分かっている問題](/ja/developers/known-problems)）。
