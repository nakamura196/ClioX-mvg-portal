# Try the trial site

The trial site is **[cliox.ldas.jp](https://cliox.ldas.jp)**.
It is a copy of Clio-X that runs on Sepolia, a public _test_ network.
Nothing on it costs real money, and nothing you do there affects the real Clio-X.

## Look around (no wallet, nothing to install)

1. Open [cliox.ldas.jp](https://cliox.ldas.jp). To switch to Japanese, use the language menu at the top.
2. Open the **Catalogue** and look at the list of records.
   You will see our two sample records near the top, and some test records published by other people.
3. Open **Declaration of Independence (1776) - sample record**.
   Read the page from top to bottom: title, description, who published it, the identifier, the change history.
4. Look at how the record can be used. For this one, the answer is **compute**: the file is not handed out.
   An approved analysis can run where the file is, and only the result comes back.

That is all you need to see what Clio-X does. None of these steps changes anything.

## What the sample shows

We published the text of the US Declaration of Independence (public domain) and a small analysis that counts the most frequent words.
On 26 September 2026 we ran the analysis on the trial service. The text stayed on the service, and only the result came back:
1,338 words in total, the most frequent being _people_ (10), _laws_ (9) and _states_ (8).
This is the same result as running the analysis on our own computer.

## Running an analysis yourself

Running an analysis needs a wallet with some test currency and permission on the trial service.
At the moment only a few addresses are allowed.
If you would like to try, please ask the site's author; the steps for developers are in [CLI: publish and free compute](/developers/trial-run).

## Please keep in mind

- This is a study run by one researcher, not a Clio-X service. It may be changed or stopped.
- Do not publish real or sensitive records here. Anything written to the ledger stays there.
- Some pages that work on the real Clio-X may not work here yet.
