# For the Clio-X project

These pages are for Vicki Lemieux's group and the Clio-X team.
They report what was built and found in September 2026, and list the decisions we would like to make together.

## Why this work

Clio-X can help archivists without an IT background see why data and computing matter to their work.
Many of them are wary of information technology.
So the prototypes below try to lower that fear first: archival vocabulary, a way to look without risk, and watching before touching.

A second aim was practical: to let people try Clio-X **without Pontus-X membership**.
For that we set up a trial on the Sepolia test network, with our own Ocean Node and subgraph.

## In short

- The trial runs at [cliox.ldas.jp](https://cliox.ldas.jp) and has been public since 26 September 2026. It uses test currency only.
- A full cycle worked there: publish a record and an analysis, run the analysis on the node, get only the result back.
- The most important finding is not technical: **records stay tied to the service that published them.**
  When that service closes, the records vanish from every catalogue although nothing was deleted.
  This matters for custody and permanence, and we have written it up for archivists:
  [When the publishing service closes](/archivists/when-a-node-closes).
